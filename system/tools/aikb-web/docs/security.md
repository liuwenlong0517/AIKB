# 第一阶段安全边界

- 服务固定绑定 `127.0.0.1`，启动脚本不接受监听地址；
- 只提供 GET/OPTIONS 只读接口，不执行脚本或写入正式知识；
- 文档只接受 `aikb:` 稳定 ID 或 `content/...` 逻辑路径；
- 绝对路径、盘符、空字节和目录穿越被拒绝；
- API 不返回物理路径、数据库路径、traceback 或底层异常文本；
- 搜索、目录、标签和正文都强制过滤 `verified`；
- Markdown 不启用原始 HTML，并通过 `rehype-sanitize` 过滤危险协议和标签；
- 开发 CORS 只允许本机 Vite 端口，生产模式使用同源静态资源；
- 自动索引重建只修改 `workspace/db/` 派生数据，不修改 Markdown/Git 事实源。

如果未来开放局域网访问，必须先补充身份认证、CSRF、权限、TLS/可信反向代理和部署审计，不能仅把监听地址改成 `0.0.0.0`。
