# AIKB WebUI 阶段 3 页面与空状态设计

阶段 3 是 Windows 本地受控管理终端。知识、规则和 Git 事实源继续只读；页面新增三项静态白名单动作及任务中心，不提供任意命令、脚本路径、环境变量、原始诊断下载或 Git 写操作入口。

## 信息架构

左侧常驻导航按以下顺序排列：

1. 总览 /
2. 知识库 /knowledge
3. 知识搜索 /search
4. 运行状态 /runtime
5. 审计日志 /audit
6. 任务中心 /tasks
7. 系统状态 /system

规则管理、设置和原始诊断下载不显示为“即将可用”的空入口。顶部栏展示“本地受控管理模式”和本机标识；不展示物理路径。右侧内容区独立滚动，导航和顶部栏固定，长页提供回到页首按钮。

## 页面职责

### 总览

展示 verified 正式知识数量、类型/标签分布、索引可用性、最近验证条目、活动 Working State 数量和审计最近活动摘要。各卡片来自独立读接口；单卡失败只在该卡显示降级，不把整页伪装成空白。

### 知识库与阅读

知识库显示 content 逻辑目录树、条目类型和 verified 状态。阅读页展示标题、稳定 ID、逻辑路径、类型、标签、适用版本、验证时间、哈希、关系和 Markdown 正文。正文保留标题层级、列表、代码块和换行；禁止 raw HTML。

### 知识搜索

提供关键词、类型、标签筛选和分页。类型与标签来自正式元数据；多条件取交集。结果显示标题、逻辑路径、命中章节、限长摘要和 verified 状态。无命中与索引不可用必须区分。

### 运行状态

页面分为“活动任务列表”和“任务详情”两级：

- 列表只列活动状态 planned、active、blocked，默认按 updated_at 最新时间倒序；不支持归档或关闭任务搜索。列出 work_id、项目逻辑 ID、状态、Agent、角色、更新时间、最新检查点、脏状态和仓库摘要；分页上限遵循 API 的 50。
- 详情展示目标、当前状态、下一步、阻塞、白名单恢复章节、仓库安全摘要和检查点历史入口。
- 检查点详情只显示有限恢复信息和验证/变更文件的逻辑路径；不显示物理路径、完整 diff、聊天或隐藏推理。
- session_id=null 时显示“未提供会话 ID”；没有真实 session_label 时显示“未提供会话标签”，不能用其他字段补齐。

状态徽章固定映射：planned 计划中、active 进行中、blocked 已阻塞。关闭状态不在第一小版本页面中出现。

### 审计日志

页面分为“摘要”和“调用列表/详情”：

- 摘要显示总调用数、状态分布、Agent/来源分布、操作分布、平均耗时、fallback 数、损坏数和最近活动时间。
- 列表支持时间范围（since 或日期）、Agent、来源、状态、操作筛选和分页；默认按 started_at 最新时间倒序。
- 列表优先显示会话标签、Agent、来源、动作说明、结果说明、状态、耗时和降级标志。session_id、invocation_id 置于可展开的技术信息区；缺失的 session_label 保持 null 并显示“未提供会话标签”。
- 详情显示开始/结束时间、调用 ID、动作/结果安全说明、错误类型、捕获级别和 fallback；不显示原始 client、action、result_summary、诊断正文或附件存在性。

状态徽章固定映射：started 已开始、succeeded 成功、failed 失败、noop 无操作、blocked 已阻止、incomplete 未完成、cancelled 已取消、timed_out 已超时、interrupted 已中断。来源筛选同时支持 mcp、hook 和 web。

### 任务中心

动作卡片只展示服务端注册的“结构校验、控制仓状态、知识仓状态”。用户必须先查看语义预览，再使用服务端签发的单次令牌创建任务；页面没有命令、路径或环境编辑框。

任务列表展示动作、状态、更新时间和任务 ID；详情展示安全输出、裁剪提示、结构化结果和审计关联。SSE 用于实时更新，连接失败时非终态任务每约 2 秒轮询快照，进入成功、失败、取消、超时或中断后停止。刷新 `/tasks/{task_id}` 必须恢复最终投影。

### 系统状态

展示平台、架构、Python 版本、控制仓/知识仓分支与短提交、脏状态、索引状态和能力矩阵。仓库只显示逻辑角色，不显示物理路径、远端或完整 Git 输出。`controlled.actions` 以真实初始化结果显示，不能沿用阶段 2 的固定不支持文案。

## 统一状态与空状态

每个页面/卡片必须区分以下状态，并提供可操作但不产生副作用的建议：

| 状态 | 展示 | 文案示例 |
|---|---|---|
| 加载中 | 骨架屏或局部 spinner | “正在读取本机只读数据…” |
| 合法空集 | 空插图/图标、说明和筛选提示 | “当前没有活动任务。”、“没有匹配的审计调用。”、“尚无执行任务。” |
| 局部降级 | 黄色提示条、保留可信数据 | “索引不可用，当前结果可能不完整。” |
| 完全不可用 | 错误卡片、request ID、重试 | “运行状态暂时不可用，请稍后重试。” |
| 参数错误 | 就地字段提示 | “页大小必须在 1 到 50 之间。” |
| 未找到 | 404 资源说明和返回列表 | “未找到该任务或它已不在活动范围内。” |

知识、运行状态和审计空状态不得出现写入或修复按钮。任务中心只允许从三项注册动作进入预览，不提供“执行脚本”“修复索引”“清理日志”等入口。

## 降级与安全显示

meta.warnings 映射为人类文案：index_unavailable→“索引不可用”、audit_partial→“审计记录部分不可读”、damaged_records→“存在损坏记录”、session_id_unavailable→“部分记录未提供真实会话 ID”。警告不应展示底层文件、异常、堆栈或诊断附件路径。

逻辑路径可以复制；绝对路径、数据库位置、完整 Git 输出、诊断正文、聊天全文、transcript 和隐藏推理永远不渲染。长文本默认折叠并显示字符数/截断标志，Markdown 代码块支持横向滚动。

## 浏览器验收门槛

必须覆盖：总览/知识/搜索/运行/审计/任务中心/系统七个主路由；任务、Working State、检查点和调用详情深链刷新不返回后端 404；搜索无命中与索引故障可区分；任务能从预览进入终态且 SSE 断开后由轮询收敛；关联知识方向与类型只显示中文；Markdown 块结构和危险 HTML 被安全渲染；页面、错误和网络响应中均无物理路径、命令、令牌、诊断正文和 traceback；未知 /api/v1/* 返回 JSON 错误而不是 SPA HTML。
