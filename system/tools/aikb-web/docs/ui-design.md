# 第一阶段页面设计

侧栏只显示总览、知识库、知识搜索和系统状态。控制中心、规则管理、检查点和审计日志在实现前不展示空入口。桌面端侧栏固定为常驻导航且不提供折叠入口，顶部栏和侧栏不随正文滚动；右侧内容区独立滚动，长页面在右下角提供回到页首按钮。

- 总览：正式知识数量、类型、标签、索引和最近验证条目；
- 知识库：逻辑目录树和只读说明；
- 搜索：关键词、类型、标签、命中章节和摘要；类型与标签使用正式知识元数据选择器，仅用于缩小关键词结果，两个条件同时选择时取交集；
- 阅读：Markdown 正文、稳定 ID、逻辑路径、类型、标签、适用版本、验证日期、哈希和关系；
- 系统状态：平台、架构、Python、双仓 Git 摘要、索引和阶段能力。

页面优先适配桌面宽度，窄屏只做基础折行，不承诺第一阶段移动端专项体验。
