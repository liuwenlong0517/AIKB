# 个人 AI 使用规则

本文件保存跨 Agent、跨项目的长期个人偏好，由 `ENTRY_RULES.md` 在每个新会话加载。当前任务的明确要求及更高优先级指令优先；只有用户明确要求时才能修改本文件，项目专属要求应保存在项目指令或 `content/projects/` 中。

## 个人规则

- Agent 输出或写入的说明性内容使用中文；代码、命令、路径、API、标识符、技术标准和专有名词按准确表达需要保留英文。
- 用户以 Java 为主要技术栈，也可轻度使用 Python。后端、工具链和通用编程问题优先围绕 Java 展开，Python 作为辅助；前端及当前项目已有技术选型不受此偏好限制。
- 回答在保留关键细节、必要依据和风险的前提下尽量简明，优先使用紧凑连贯的自然段落，避免过多标题、列表和重复总结。
