# AIKB Agent Root Instruction

将以下内容复制到具体 Agent 的根指令文件中：

```md
## AIKB 接入

AIKB 位于 `E:\CodeSpace\AIKB`。

在每个新项目或新会话开始时，如果当前上下文中尚未完成 AIKB 接入，则先读取 `E:\CodeSpace\AIKB\AI_RULES.md`，再按照其中的初始化流程读取个人规则、索引和必要知识，并在完成后向用户反馈已接入 AIKB。

本次会话后续持续遵循已加载的 AIKB 规则，并将已加载知识作为当前上下文记忆使用，不得在每轮对话中重复读取。仅在用户要求重载、上下文丢失、开启新会话或 `AI_RULES.md` 规定的其他情况下重新加载。

在任务执行过程中，按照 `AI_RULES.md` 主动发现、验证并写入值得长期保留的知识。

在符合 `AI_RULES.md` 写入规则的前提下，允许 Agent 直接新增或更新 AIKB 内容，无需为每次常规知识写入单独请求确认；涉及敏感信息、争议结论或需要替用户作出新的长期决策时除外。
```
